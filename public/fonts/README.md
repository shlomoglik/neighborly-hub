# Self-hosted Neighborly 2b fonts

Font files are the Google Fonts TrueType distributions, obtained through the official Google Fonts CSS service. CSS declarations specify normal style, swap display and explicit weights.

| Family       | Weights            | Source                                                    |
| ------------ | ------------------ | --------------------------------------------------------- |
| Heebo        | 400, 500, 600, 700 | https://github.com/google/fonts/tree/main/ofl/heebo       |
| Varela Round | 400                | https://github.com/google/fonts/tree/main/ofl/varelaround |
| Nunito       | 600, 700           | https://github.com/google/fonts/tree/main/ofl/nunito      |
| Roboto       | 400, 500, 600, 700 | https://github.com/google/fonts/tree/main/ofl/roboto      |

The accompanying family-specific OFL files retain upstream copyright and license notices. Application and Storybook bundlers resolve relative URLs from `fonts.css`; no external font request is required at runtime.
